# Netflix-data-analysis

An Exploratory Data Analysis (EDA) project on the Netflix Movies & TV Shows dataset using Python. This project uncovers valuable insights into Netflix's content library by analyzing content type, release trends, ratings, duration, and country-wise distribution through data visualization.

---

## 📌 Project Overview

The objective of this project is to explore Netflix's content catalog and answer business-related questions using data analysis techniques. The project focuses on understanding content distribution, identifying growth trends, and extracting meaningful insights that can support data-driven decision-making.

---

## 🎯 Objectives

- Analyze the distribution of Movies and TV Shows.
- Study Netflix's content growth over the years.
- Identify the top content-producing countries.
- Explore content ratings and audience preferences.
- Analyze movie durations and TV show seasons.
- Generate actionable business insights through visualizations.

---

## 📊 Data Analysis Workflow

### 1. Data Collection
- Imported Netflix dataset into Jupyter Notebook.

### 2. Data Cleaning
- Checked missing values.
- Removed duplicate records.
- Formatted columns.
- Handled null values where required.

### 3. Exploratory Data Analysis (EDA)
- Movies vs TV Shows distribution
- Content growth over years
- Country-wise content distribution
- Rating distribution
- Duration analysis
- Genre exploration

### 4. Data Visualization
Created visualizations using Matplotlib and Seaborn to identify trends and patterns.

---

## 📈 Key Insights

- 🎥 Movies make up the majority of Netflix's content library.
- 📈 Netflix experienced rapid content growth after 2015.
- 🌍 United States, India, and the United Kingdom contribute the highest number of titles.
- ⭐ TV-MA is the most common content rating.
- 🎬 Most movies have a duration between 80–120 minutes.
- 📺 TV Shows are generally released with fewer seasons.
